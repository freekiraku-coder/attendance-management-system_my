# 勤怠管理システム

## 概要
社員の出勤・退勤・休憩時間を管理できる勤怠管理システムです。  
ログイン機能、勤怠登録、勤怠一覧表示などを実装予定です。

ポートフォリオ兼学習用として作成しています。

---

# システム概要

## 主な機能

- ログイン機能
- ユーザー管理
- 勤怠登録
- 勤怠一覧表示
- 月次勤怠確認
- 管理者機能
